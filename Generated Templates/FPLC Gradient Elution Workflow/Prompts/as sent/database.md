# Database agent — prompt as sent

> The payload the database agent received for *eLabFTW field units and meanings (`custom_instructions`)* in the replication study, identical across all 20 replicates.
> No separate wizard prompt: this text is supplied by the application itself.

---

```text
These eLabFTW fields carry the units and meanings below. Use them when choosing column names, column units and descriptions - do not infer units from the field names:
- Process ID (Linked Process ID (do not modify))
- CIP_DURATION (unit: s; CIP Hight Salt - Duration)
- WASH_DURATION (unit: s; Wash - Duration)
- CIP_3_DURATION (unit: s; CIP H2O 1 - Duration)
- CIP_4_DURATION (unit: s; CIP HCl - Duration)
- CIP_5_DURATION (unit: s; CIP H2O 2 - Duration)
- WASH_FLOW_RATE (unit: mL/min; Wash - Flow Rate)
- CIP_2_HOLD_DURATION (CIP NaOH - hold_duration)
- LOAD_INJECT_DURATION (unit: s; Load / Inject - Duration)
- LOAD_INJECT_FLOW_RATE (unit: mL/min; Load / Inject - Flow Rate)
- EQUILIBRATION_DURATION (unit: s; Equilibration - Duration)
- ELUTE_GRADIENT_DURATION (unit: s; Elute (Gradient) - Duration)
- EQUILIBRATION_FLOW_RATE (unit: mL/min; Equilibration - Flow Rate)
- ELUTE_GRADIENT_GRADIENT_END (unit: %; Elute (Gradient) - Gradient End)
- ELUTE_GRADIENT_GRADIENT_START (unit: %; Elute (Gradient) - Gradient Start)
```
