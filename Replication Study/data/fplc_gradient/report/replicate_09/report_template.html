3. Methods

Overview of Automated Workflow:

  1. Manual Preparation:
    • Pause step executed with instruction: "Manually fill sample loop".
    • Operator fills the ÄKTA sample loop with the prepared sample according to the experimental plan.
  2. ÄKTA Pure - Automated Chromatography Run:
    • ÄKTA Pure system started using a predefined method controlling column loading, washing, elution, and cleaning-in-place (CIP) phases.
    • System recorded UV signal (uv1) and conductivity (cond) throughout the run at 1 s sampling intervals.
