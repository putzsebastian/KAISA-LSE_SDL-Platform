3. Methods

3.1 Overview of Automated Workflow

The ÄKTA Pure chromatography run was executed using an automated workflow consisting of a brief manual preparation step followed by an automated protocol on the ÄKTA system.

  • Manual preparation (Utility – Pause): The system was paused with the instruction to manually fill the sample loop prior to starting the automated run.
  • ÄKTA Pure – Run Protocol: After the sample loop was filled, the ÄKTA Pure system executed the predefined method while recording UV (uv1) and conductivity (cond) signals with a sampling time of 1 s.
