Methods

The ÄKTA Pure chromatography run was executed using an automated protocol with a manual sample loading step followed by the programmed method phases.

Overview of Automated Workflow
  1. Manual Sample Loading
    • The system was paused to allow manual filling of the sample loop as indicated by the workflow message "Manually fill sample loop".
    • Once the sample loop was filled, the run was resumed to start the automated ÄKTA protocol.
  2. ÄKTA Pure Protocol Execution
    • The programmed ÄKTA Pure method was started using the "Run Protocol" operation.
    • During the run, UV (uv1) and conductivity (cond) signals were continuously monitored and recorded at the defined sampling interval.
    • The following time-based phases were included in the method (durations refer to column processing steps):
