3. Methods

Overview of Automated Workflow:

  1. Manual Sample Loading (Utility - Pause)
    • The system was paused with the instruction: "Manually fill sample loop".
    • The sample loop was manually filled with the prepared sample before starting the ÄKTA method.
  2. ÄKTA Pure Chromatography Run (AKTA Pure - Run Protocol)
    • The predefined ÄKTA Pure protocol was started after manual loop filling.
    • Sample monitoring signals recorded during the run included:
      • UV signal: uv1
      • Conductivity signal: cond
    • Sample data were acquired with a sampling time of 1 s per point.
