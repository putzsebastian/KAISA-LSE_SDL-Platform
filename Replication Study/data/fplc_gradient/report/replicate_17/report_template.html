3. Methods

3.1 Automated Workflow Description
  1. Manual Preparation:
    • The system was paused with the instruction: "Manually fill sample loop".
    • The sample loop was filled manually with the chromatography sample according to the experimental plan.
  2. ÄKTA Pure Run:
    • The predefined ÄKTA Pure protocol was started using the automation workflow.
    • UV (uv1) and conductivity (cond) signals were recorded during the run with a sample interval of 1 second.
