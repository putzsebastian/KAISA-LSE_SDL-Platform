3. Methods

3.1 Overview of Automated Workflow
  1. Manual Sample Loading
    • The run is initiated with a manual pause step to allow the operator to fill the sample loop ("Manually fill sample loop").
  2. ÄKTA Pure Chromatography Run
    • The ÄKTA Pure system executes the predefined protocol controlled by the automation workflow.
    • Online signals acquired during the run include UV (uv1) and conductivity (cond), sampled at a fixed interval of 1 second.
