3. Methods

Overview of Automated Workflow

  1. Manual Sample Loading
    • The workflow starts with a manual pause step prompting the user with the message: "Manually fill sample loop".
    • The sample loop is filled with the prepared sample according to the experimental plan before continuing the automated run.
  2. ÄKTA Pure Chromatography Run
    • The ÄKTA Pure system executes a predefined protocol with online monitoring of UV (uv1) and conductivity (cond) signals.
    • Data are recorded with a sample time of 1 second for all monitored signals.
