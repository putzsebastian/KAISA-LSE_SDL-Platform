3. Methods

The ÄKTA Pure chromatography run was executed using an automated workflow consisting of a manual preparation step followed by execution of the predefined ÄKTA protocol.

3.1 Manual Preparation
  • The system was paused with the instruction: "Manually fill sample loop" prior to starting the automated ÄKTA run.
  • Sample was loaded into the ÄKTA sample loop according to the experimental plan.
