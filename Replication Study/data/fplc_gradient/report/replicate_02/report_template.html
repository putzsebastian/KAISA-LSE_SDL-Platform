3. Methods

3.1 Automated Workflow Description
  1. Manual Sample Loading
    • The system pauses with the instruction: "Manually fill sample loop".
    • The operator fills the ÄKTA sample loop with the prepared sample according to the experimental plan.
  2. ÄKTA Pure Run Protocol
    • The ÄKTA Pure chromatography system executes a predefined method.
    • Sampling interval for chromatography signals: 1 s (for UV and conductivity).
    • Online signals recorded: UV (uv1), Conductivity (cond).
