3. Methods

3.1 Automated Workflow Description
  1. Manual Sample Loading (Utility — Pause):
    • The system was paused with the instruction: "Manually fill sample loop".
    • The operator manually filled the ÄKTA sample loop with the prepared sample before continuing the run.
  2. Chromatography Run (ÄKTA Pure — Run Protocol):
    • The ÄKTA Pure system was started and the pre-configured method was executed.
    • Sample monitoring signals recorded during the run:
      • UV signal: uv1
      • Conductivity signal: cond
    • Sampling interval for recording process data: 1 s.
