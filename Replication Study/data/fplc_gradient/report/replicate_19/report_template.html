Methods

The ÄKTA Pure chromatography run was executed using an automated workflow with manual sample loading followed by an automated protocol on the ÄKTA Pure system.

Automated Workflow Description
  1. Manual Preparation:
    • The system was paused with the instruction: "Manually fill sample loop" to allow the operator to load the sample into the injection loop.
  2. ÄKTA Pure Run Protocol:
    • The ÄKTA Pure system was started with a defined protocol.
    • Sample signals recorded during the run included UV (uv1) and conductivity (cond).
    • Sample data sampling interval: 1 second.
