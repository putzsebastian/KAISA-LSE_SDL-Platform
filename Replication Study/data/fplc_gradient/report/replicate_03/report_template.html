3. Methods

The ÄKTA Pure chromatography run was executed using an automated workflow consisting of a manual loading step followed by an instrument-controlled protocol.

3.1 Workflow Overview
  1. Manual Sample Loading
    • The system was paused with the instruction: "Manually fill sample loop".
    • The operator manually filled the ÄKTA sample loop with the prepared sample.
  2. ÄKTA Pure Protocol Execution
    • The ÄKTA Pure system was started in automated mode to execute the predefined protocol.
    • Sample signals recorded included UV absorbance (uv1) and conductivity (cond) with a sampling time of 1 second.
