Methods

The ÄKTA chromatography run was executed using an automated workflow comprising manual sample loading followed by an ÄKTA Pure protocol run. The workflow consisted of the following main steps:

  1. Manual Preparation
    • Utility pause step prompted the operator to manually fill the sample loop according to the experimental plan ("Manually fill sample loop").
    • After confirmation, the automated workflow resumed.
  2. ÄKTA Pure Chromatography Run
    • The predefined ÄKTA method was started via the automation interface ("Run Protocol").
    • During the run, the following sample signals were recorded at the system sampling interval:
      • UV signal (uv1)
      • Conductivity (cond)
    • Sample data were acquired with a sampling time of 1 second throughout the run.
