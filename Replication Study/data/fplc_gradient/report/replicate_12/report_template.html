3. Methods

Overview: Automated ÄKTA Pure chromatography run with manual sample loading followed by execution of a predefined protocol on the ÄKTA system. UV and conductivity signals were recorded during the run.

3.1 Workflow Description
  1. Manual Sample Loading
    • The run was initiated with a manual step to fill the sample loop as prompted by the workflow ("Manually fill sample loop").
    • After confirming that the sample loop was filled, the automated protocol continued.
  2. ÄKTA Pure Protocol Execution
    • The AKTA Pure system executed the configured chromatography protocol.
    • UV signal (channel: uv1) and conductivity (channel: cond) were continuously monitored and recorded throughout the run.
    • Sampling interval for process data acquisition: 1 s.
